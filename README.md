# Sherpa East Studio

Vue-3-Projekt mit TypeScript, Vite, Vue Router, Pinia, ESLint und Prettier.

## Entwicklung

```sh
npm install
npm run dev
```

## Produktion

```sh
npm run build
```

## Assets

- Logos: `src/assets/logos/`
- Bilder: `src/assets/images/`
- Audio: `src/assets/audio/`
- Favicon: `public/favicon.png`
